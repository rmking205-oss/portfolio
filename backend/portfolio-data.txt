INDEPENDENT PROJECT

Project Name: Quiz Bio System

Project Type: Independent Project

Description:
A complete quiz application focused on secure online assessment, student identification and biometric verification.

Technologies:
HTML
CSS
JavaScript
Face API

Overview:
Quiz Bio System is an independently developed web application for conducting controlled online quizzes. The project combines quiz functionality with identity verification and anti-cheating mechanisms.

Features:
Student identification
Timed quiz
Multiple-choice questions
Face detection
Identity verification
Tab switching detection
Violation counting
Automatic submission
Right-click prevention
Copy and paste prevention

My Contribution:
I designed and developed this project independently. My work included the application structure, quiz functionality, user interface, security mechanisms and biometric identity verification.

How It Works:
The application identifies the student before the quiz begins. Questions are displayed through JavaScript and the timer controls the assessment duration. Browser activity is monitored for violations and face detection can be used for identity verification.

Challenges:
One of the biggest challenges was combining the quiz functionality with security features without negatively affecting the user experience. Webcam access and face detection also required careful implementation.

What I Learned:
This project improved my understanding of JavaScript, browser events, webcam access, face detection, application state and building a complete web application independently.
